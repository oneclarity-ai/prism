# Support

Prism is a pre-release community project. Maintainers do not provide guaranteed response times,
production support, tenant administration, or incident response.

Use GitHub Issues for reproducible bugs and approved feature requests. Include the Prism commit,
Python/PostgreSQL versions, deployment method, sanitized logs, expected behavior, and actual
behavior. Do not include credentials, tenant identifiers, employee messages, or personal data.

Use GitHub Discussions for setup questions and design conversations when Discussions are enabled.
Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not the public support channels.

Questions about Microsoft 365 licensing, tenant policy, consent, or Azure service availability
should be directed to the relevant service provider or your tenant administrator.
